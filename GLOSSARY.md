# Глоссарий

- **Гейтвей** — сервис с OpenAI-совместимым HTTP API, через который проходят все вызовы LLM. Кэш, лимиты, fallback, маршрутизация, учёт стоимости.
- **Провайдер** — конкретный источник ответов LLM за гейтвеем: Claude или локальный OpenAI-совместимый сервер.
- **Расследование** — одна попытка системы разобрать один алерт от начала до итогового отчёта. Единица учёта стоимости.
- **Алерт** — входное событие (например, рост латентности или всплеск 500), с которого начинается расследование.
- **Оркестратор** — компонент, разбивающий расследование на подзадачи и раздающий их воркерам.
- **Воркер** — агент, решающий одну подзадачу расследования (метрики, логи, знания) циклом из вызовов tools.
- **Tool** — функция, которую модель может вызвать (запрос метрик, поиск в логах, поиск в ранбуках).
- **Сложность запроса** — подсказка клиента гейтвею: простой запрос (классификация, краткое резюме) уходит на локальную модель, сложный на Claude.
- **Алиас модели** — значение поля `model` в запросе к гейтвею: `auto` включает маршрутизацию по сложности, конкретное имя закрепляет запрос за моделью.
- **Шов (seam)** — точка, через которую тесты проверяют поведение системы. Для гейтвея это его HTTP API.
- **Фейковый провайдер** — тестовый HTTP-сервер вместо настоящей модели.
- **Сценарий хаоса** — воспроизводимая поломка демо-сервиса, на которой проверяется качество агента.
- **Eval** — прогон агента по сценариям хаоса с подсчётом верных причин, стоимости и времени.
- **Ралф-цикл (Ralph loop)** — процесс разработки: агент итерирует над одним куском спеки, пока команда проверки не станет зелёной. К продукту отношения не имеет.
