# 0001. Go и прямые вызовы API без агентских фреймворков

Дата: 2026-10-23. Статус: принято.

## Решение

Проект написан на Go. Вызовы провайдеров, RAG-пайплайн, цикл агента с tool calling и стриминг реализуются напрямую, без LangChain-подобных фреймворков. Хранилище — Postgres с pgvector, кэш и лимиты — Redis.

## Почему

Цель проекта — показать понимание механики LLM-систем и backend-инженерию. Фреймворк скрывает именно ту механику, которую нужно уметь объяснить. Go отличает проект от типичных Python-демо.

## Последствия

Больше кода пишется с нуля. Запрет проверяется линтером (список запрещённых импортов).
