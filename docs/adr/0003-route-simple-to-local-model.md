# 0003. Маршрутизация простых запросов на локальную модель

Дата: 2026-10-23. Статус: принято.

## Решение

Гейтвей отправляет простые запросы (классификация алерта, краткое резюме логов) на локальную OpenAI-совместимую модель, сложные на Claude. Сложность задаёт клиент. Если вход не помещается в контекст локальной модели, запрос по умолчанию уходит на Claude. Ollama как провайдер не используется: любой OpenAI-совместимый сервер подключается по адресу.

## Почему

Локальные модели слабые (контекст 16k, низкая скорость), но бесплатные. Роутинг даёт измеримую экономию, а ограничение по контексту становится реальным условием дизайна, которое видно на метриках.

## Последствия

Eval запускается в двух режимах («только Claude» и «с роутингом»), результаты сравниваются в README. Допущения о том, кто определяет сложность и как считается стоимость локальной модели, подтверждаются при интервью к спеке гейтвея.
