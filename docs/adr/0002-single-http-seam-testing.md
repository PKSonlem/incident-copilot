# 0002. Тесты через HTTP API с фейковыми провайдерами

Дата: 2026-10-23. Статус: принято.

## Решение

Поведение слоя проверяется через его внешний HTTP API (один шов на слой). Вместо настоящих моделей работают фейковые провайдеры, то есть тестовые HTTP-серверы. Redis в тестах настоящий. Реальные модели вызываются только в отдельном eval-прогоне.

## Почему

Тесты не ломаются при рефакторинге внутренностей, остаются быстрыми, бесплатными и детерминированными, а утверждать их до реализации (TDD) проще, потому что они читаются как «запрос → ожидаемый ответ».

## Последствия

Внутренние пакеты (кэш, лимитер, роутер) не имеют собственных тестов на публичном уровне. Все их случаи проверяются как поведение сервиса.
